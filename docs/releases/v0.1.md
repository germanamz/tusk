# v0.1 — Foundation

The first release of Tusk, a fast, concurrent-safe task manager for the command line. Single binary, SQLite persistence, no external dependencies.

### Highlights

- **8 CLI commands** — `add`, `list`, `info`, `modify`, `start`, `done`, `delete`, `annotate`
- **TaskWarrior-inspired filters** — `status:pending,active`, `priority:2..4`, `due:today`, `+tag`, `-tag`
- **Pure Go SQLite with WAL mode** — no CGO required, embedded migrations, zero setup
- **Hierarchical tasks** — domain model supports projects, tags, relations, and workflows
- **Soft delete** — nothing is lost; deleted tasks stay in the DB for audit trails
- **Short IDs** — 8-char hex IDs for quick CLI use, full UUIDs under the hood
- **Text + JSON output** — pipe-friendly JSON mode for scripting

### Architecture

Clean layered design: CLI → Services → Repository interfaces → SQLite. Dependencies flow one way. Business logic never touches storage directly.

### Install

```bash
# Requires Go 1.26.1+
make install    # installs to $GOPATH/bin/tusk
```

### Quick Start

```bash
tusk add "Build something great" priority:3 +ideas
tusk add "Write tests" project:backend due:friday
tusk list status:pending +ideas
tusk start <short_id>
tusk done <short_id>
```

DB location: `--db <path>` flag > `TUSK_DB` env > `~/.local/share/tusk/tusk.db`
