# v0.2 — Relations & Hierarchy

Tusk now understands how tasks relate to each other. This release adds task hierarchies, relation tracking with cycle detection, completion propagation, full project and tag management, and a tree view for visualizing task structures.

### Highlights

**Task Hierarchy & Relations**
- Link tasks with `tusk link <id> blocks|relates_to|duplicates <id>` — DFS cycle detection prevents circular blocking chains
- Set parent tasks with `parent:<short_id>` in `tusk add` and `tusk modify`
- Visualize hierarchies with `tusk tree` (full tree or subtree rooted at a task)

**Completion Propagation**
- Parent tasks auto-complete when all children reach a trigger status
- Parents auto-revert when a child moves away from the trigger
- Configurable per-project via `tusk project modify <name> --set auto_complete_parent.trigger_status=completed`

**Project Management**
- `tusk project create`, `list`, `modify` — full project lifecycle
- Dot-path settings API (`--set key=val`, `--unset key`) for nested project configuration
- Optimistic locking on projects

**Tag Management**
- `tusk tag create`, `list`, `modify`, `delete`, `rename`
- Delete guards prevent removing tags still assigned to tasks
- `--usage` flag shows task count per tag

### New Commands

```
tusk tree [short_id] [--all]
tusk link <short_id> <type> <short_id>
tusk unlink <short_id> <type> <short_id>
tusk project list
tusk project create <name> [--description ...]
tusk project modify <name> [--description ...] [--set key=val] [--unset key]
tusk tag list [--usage] [--color ...]
tusk tag create <name> [--color ...]
tusk tag modify <name> --color ...
tusk tag delete <name>
tusk tag rename <old> <new>
```

### New Filter

```
tree:<short_id>    # all descendants (recursive)
```
