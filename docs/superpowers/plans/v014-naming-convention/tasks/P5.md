## What

Bring every file in `internal/mcp/` and `internal/portability/`
(production and tests) into compliance with STYLE.md's four rules.
Remove all four exclusion entries (two packages × two linter
configs) from both linters. Mechanical sweep; no behavior changes.

byte-identical to pre-sweep.

## Why

surface. `internal/portability/` is folded in here because no other
phase covers `internal/`-rooted code beyond `tui` and `mcp`; pairing
it keeps the directory in scope without inflating phase count.
