## What

Build `internal/lint/testhandle/` with `analyzer.go`,
`analyzer_test.go`, and `testdata/src/a/a.go`. The analyzer walks
every `*ast.FuncDecl` and `*ast.FuncType`. For each parameter, it
resolves the type and consults a hardcoded table:
`*testing.T` → `test`, `*testing.B` → `bench`, `testing.TB` →
`harness`. If the parameter's name does not match, it emits a
diagnostic. Test files use `test *testing.T`.

## Why

Rule 4 enforcement. Standardized test-handle names eliminate the
last universally-tolerated single-character identifier in Go.
