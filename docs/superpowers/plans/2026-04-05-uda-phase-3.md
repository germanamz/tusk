# UDA Phase 3: Filter Support

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `uda.key:value` filter syntax for querying tasks by UDA key-value pairs in both CLI and MCP list operations.

**Architecture:** Extend the existing 3-stage filter pipeline (Lex → Parse → Resolve) with `uda.*` prefix handling in the parser, a `UDA map[string]string` field on `domain.TaskFilter`, and `json_extract` SQL conditions in the SQLite repository's `buildFilter`. The lexer needs no changes — `uda.key:value` already tokenizes as `TokenField`.

**Tech Stack:** Go standard library, SQLite `json_extract` (built-in since 3.9.0).

**Design spec:** `docs/superpowers/specs/2026-04-05-uda-design.md`

**Prerequisites:** Phase 1 must be completed (for `domain.ValidateUDAKey`). Phase 2 must be completed before this phase — Tasks 1-4 are independent of Phase 2, but Task 5 (E2E tests) uses the `--uda` CLI flag introduced in Phase 2 to create tasks with UDA data.

```go
case TokenField:
    key, value, _ := strings.Cut(tok.Value, ":")
    // Check for uda.* prefix before static field lookup
    if strings.HasPrefix(key, "uda.") {
        udaKey := strings.TrimPrefix(key, "uda.")
        if udaKey == "" {
            errs = append(errs, ParseError{
                Pos:     tok.Pos,
                Field:   key,
                Message: "empty UDA key name",
            })
            continue
        }
        if err := domain.ValidateUDAKey(udaKey); err != nil {
            errs = append(errs, ParseError{
                Pos:     tok.Pos,
                Field:   key,
                Message: err.Error(),
            })
            continue
        }
        fs.Fields = append(fs.Fields, FieldFilter{
            Key:   key,
            Value: value,
            Pos:   tok.Pos,
        })
        continue
    }
    validator, known := fieldValidators[key]
    if !known {
        errs = append(errs, ParseError{
            Pos:     tok.Pos,
            Field:   key,
            Message: "unknown field",
        })
        continue
    }
    if err := validator(value); err != nil {
        errs = append(errs, ParseError{
            Pos:     tok.Pos,
            Field:   key,
            Message: err.Error(),
        })
        continue
    }
    fs.Fields = append(fs.Fields, FieldFilter{
        Key:   key,
        Value: value,
        Pos:   tok.Pos,
    })
```

if len(filter.UDA) > 0 {
    // Sort keys for deterministic query generation (important for tests)
    udaKeys := make([]string, 0, len(filter.UDA))
    for k := range filter.UDA {
        udaKeys = append(udaKeys, k)

    sort.Strings(udaKeys)
    for _, k := range udaKeys {
        v := filter.UDA[k]
        jsonPath := "$." + k
        if v == "" {

            conditions = append(conditions, "(json_extract(uda, ?) IS NULL OR json_extract(uda, ?) = '')")

        } else {

        }
