## tusk claude status

Report the Claude Code plugin installed in this workspace

### Synopsis

Report whether the plugin is installed, the tusk version it was installed
by against this binary's, the binary it runs and whether that resolves,
whether its MCP server is approved, and whether .mcp.json still runs a
duplicate tusk server.

```
tusk claude status [flags]
```
